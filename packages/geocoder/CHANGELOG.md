# @earthkit/geocoder

## 0.1.0

### Minor Changes

- 7ac3661: New package: headless place search as a plugin. Search as you type with Nominatim, Photon, Pelias, MapTiler or the
  app's own GeoJSON, keyboard selection and an accessible combobox hook (`useGeocoder`), fly to the result with an
  optional marker, and reverse geocoding on click.
